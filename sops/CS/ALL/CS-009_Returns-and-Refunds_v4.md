# Standard returns
Colleagues accept returns of unworn items with tags attached when the customer has a valid receipt within the returns period shown on the receipt.
Refunds are made to the original payment method.

# Returns without a receipt
If the customer has no receipt, offer an exchange or a store credit at the current selling price.
A cash refund without a receipt must not be given.
If the customer is dissatisfied, offer to call the duty manager. Only the duty manager can approve an exception.

# Faulty items
For a faulty item with a receipt, offer a refund or replacement. Record the fault type on the returns screen.
Place faulty items in the red returns bin so that they are not put back on sale.

# Suspected return fraud
Do not accuse the customer. Process the transaction as normal and inform the duty manager discreetly. Loss Prevention reviews the case.
