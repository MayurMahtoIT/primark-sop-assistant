# Alarm activation at the exit
Politely ask the customer to step aside and check the receipt for the item. Colleagues must not physically restrain, search or chase a customer.
If tags have not been removed at the till, remove them and apologise for the inconvenience.

# Suspected theft
Do not confront. Alert the duty manager and Loss Prevention discreetly using the radio code word for suspected theft.
Record the incident on the Loss Prevention log. Colleague safety always comes before stock.

# Aggressive customers
Step back, keep a calm tone, and call the duty manager immediately. If you feel unsafe, use the panic alarm.
